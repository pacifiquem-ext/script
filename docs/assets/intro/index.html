WHAT IT IS

One workspace Library. Real AI context.

  • Library — folders, uploads, URL import, status polling
  • Ingestion — extract → chunk → Voyage embeddings
  • Chat — Claude + pgvector, SSE streaming, citations
  • Multi-tenant — workspaces, credits, API keys, privacy

DATA FLOW

Ingest once. Query fast.

Upload / URL→ Storage→ Worker extract→ Chunk + Voyage→ pgvector
Chat query→ Embed query→ Top-K chunks→ Claude stream→ Citations

QUICKSTART

Run it locally

pnpm install
cp client/.env.example client/.env
cp server/.env.example server/.env
# DATABASE_URL, JWT_SECRET, VOYAGE_API_KEY,
# ANTHROPIC_API_KEY, UPLOADTHING_TOKEN — see ENV.md

pnpm deps:up      # Redis + Postgres(pgvector) + Garage
pnpm dev:app      # client + API + worker

Health: http://localhost:4000/health · App: http://localhost:5173
